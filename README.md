# Proyecto de AltoCampoo

## 1. Vision del proyecto

Este sera un proyecto sobre una aplicacion movil sobre guias de ruta en alto campoo en la que comparte catalogo con la web.
Ademas de que se agregará en la aplicacion algunas herramientas de ayuda como calendario, accesibilidad para personas con ciertas
discapacidades.

Este proyecto funcionara tanto en español como en ingles (Si hay tiempo de sobra, se podria agregar un tercer idioma).
